# Lanaria Studio

Build a web app called Tessella — a tool for designing custom needlepoint (tapestry) canvases. It has three main sections shown as tabs: "Canvas Design", "Stitch Chart", and "Order". Use a warm, heritage aesthetic: a limewash ivory background (#F3EEE0), deep mossy green accents (#3B4F35), and an elegant serif font (Georgia or similar). The Canvas Design tab is an accordion with these steps, one open at a time: 1) Thread Brand, 2) Image, 3) Text & Lettering, 4) Monogram, 5) Border & Frame, 6) Image Tuning, 7) Canvas Specification. Set up Supabase for the backend. Don't build the logic yet — just the layout and navigation.
